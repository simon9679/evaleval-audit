# AUDIT PREREGISTRATION - INITIAL STATE

Status: FREEZE ONLY

No confirmatory audit test has been selected or executed.

Any observations made before this preregistration are excluded from confirmatory
findings. They may only appear later in a clearly labelled exploratory appendix.

## Audit objective

Evaluate EvalEval claims independently and neutrally.

The audit has no project-level PASS or FAIL target. Verdicts are scoped to a claim
and to the admissible measurement instrument used to test that claim.

## Allowed terminal statuses

- CONFIRMED
- REFUTED
- INCONCLUSIVE
- ERROR
- DESCRIPTIVE

DESCRIPTIVE is used when no verdict-bearing instrument is admissible.

## Test selection rule

After the freeze succeeds, eligible tests are selected according to protocol
dependency order:

1. dataset and instrument validity roots
2. reproducibility roots
3. measurement variation and sensitivity
4. provenance
5. independent calibration
6. corpus-level and product-level claims

## Known-issue rule

Problems disclosed by EvalEval before confirmatory test selection are recorded in a
separate known-issues baseline and are not counted as independent discoveries.
