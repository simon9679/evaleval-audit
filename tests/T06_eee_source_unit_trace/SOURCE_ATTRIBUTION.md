order:

1. registry metric unit;
2. EEE per-record `metric_config.metric_unit`;
3. proportion-shape heuristic;

`metric_unit_provenance = "eee_record"`.

The only documented unit normalization performed at this layer is:

`percentage -> percent`

Stage B carries that path as `source_record_path` and assigns a zero-based
`result_idx` to each `evaluation_results[]` entry.
