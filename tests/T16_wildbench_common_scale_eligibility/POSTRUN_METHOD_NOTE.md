# POSTRUN_METHOD_NOTE — T16

Status: final post-run meta-audit note.

T16 used a deliberately narrow eligibility predicate.

It did not interpret names as formulas and did not invent a normalization.

This keeps the verdict at the same granularity as the structured evidence.

A useful methodological distinction is:

- source-scale heterogeneity;
- explicit represented transformation;
- semantic equivalence;
- production aggregation policy.

These are separate questions and should not be collapsed into one verdict.
