T05 demonstrates a useful provenance-gating pattern.

A visually striking mixed-unit pattern can invite semantic interpretation too
early. Instead, the audit first decomposed the frozen structural pathways.

The result eliminated:

- multi-raw-label convergence;
- partial resolution;
- mixed canonical ids;
- mixed resolution strategies;
- mixed unit-provenance layers.

All 1,234 groups reduced to one structural pattern:

`one metric_raw -> one metric_id -> exact resolution -> eee_record unit provenance`

This does not finish the attribution, but it reduces the next test to a direct
source-record verification problem.

verified against the referenced source artifact.
